# Wohnungsdatenbank · Mietwohnungen in Köln

Statische Startseite in `dist/`. Lokal starten:

```sh
python3 -m http.server 8765 --directory dist
```

Dann http://localhost:8765 öffnen. Sobald der Download bereitsteht, in
`dist/index.html` die deaktivierte Schaltfläche durch einen Link zum
Anbieter der Anwendung ersetzen und den Hinweis darunter entfernen.
